## Data augmentation
The '*get_transforms*' function is applied exclusively to the training data. It performs a set of image augmentation operations, each selected at random with equal probability. These operations include:
- Data diversification through geometric transformations such as rotation, translation, scaling, mirroring, cropping, and shifting. These techniques artificially expand the dataset and improve model generalization by reducing overfitting.
- The input, target dataset was normalized using Min–Max normalization to the range (−1, 1).

```python
def get_transforms(image_size: int, train=True):
    random_choice = v2.RandomChoice([
        v2.RandomPerspective(
                    distortion_scale=0.15, # controls how much each corner can move. 
                    p=1.0),                # probability of applying the effect
        v2.RandomRotation(degrees=30),     # rotates an image with random angle
        v2.RandomAffine(
                    degrees=30,             # rotation ±30
                    translate=(0.15, 0.15), # horizontal/vertical translation as fraction of image
                    scale=(0.75, 1.05),     # scale factor
                    shear=10),              # shear angle ±10°
        v2.RandomResizedCrop(
                    size=image_size,
                    scale=(0.75, 1.),  # range of area proportion to crop from the original image
                    ratio=(0.8,  1.)), # range of aspect ratio (width/height)
        v2.RandomHorizontalFlip(),
        v2.Identity(),  # returns the input image unchanged
    ])
    if (train): # apply random geometric transformations such as rotation, translation, scaling, mirroring, cropping, and shifting
        transforms = v2.Compose([
            # if use 'ToImage' tensor should be numpy array!!!
            v2.ToImage(), # data are transorm to torch tensor in Dataset manager, tensor should be numpy array!!!
            random_choice,
            v2.ToDtype(torch.float32, scale=False), # do not convert uint8 [0,255] -> float32 [0,1]
            v2.Normalize(mean=(127.5,), std=(127.5,), inplace=True),
        ])
    else:
        transforms = v2.Compose([
            v2.ToImage(), # data are transorm to torch tensor in Dataset manager, tensor should be numpy array!!!
            v2.ToDtype(torch.float32, scale=False), # do not convert uint8 [0,255] -> float32 [0,1]
            v2.Normalize(mean=(127.5,), std=(127.5,), inplace=True),
        ])
    return transforms
```

During training, augmented images are transformed to conform to the output's technical requirements, (to 1x28x28 grayscale horizontally and vertically flipped images).

## Build UNetResNet
Designed a `UNetResNet` model in which the encoder follows a `ResNet` architecture, while an attention mechanism is used to modulate the input features.
To define the architecture of the `UNetResNet` model, we use the configuration described below, where each component specifies a distinct part of the network:
- input: configuration of the input layer associated with the attention mechanism
    - img_shape: spatial dimensions of the input image
    - out_channels: number of output channels
    - frame_dim: size of the fixed patches into which the input is partitioned
    - num_heads: number of parallel attention heads; the embedding dimension is evenly divided across heads (i.e., each head has dimension embed_dim / num_heads)
- encode: configuration of the encoder, where each entry corresponds to a configurable ResNet block
    - in_channels: number of input channels
    - expansion: channel expansion factor used within the residual blocks
    - stride: convolution stride
    - intermediate_channels: number of intermediate feature channels
    - num_residual_blocks: number of residual blocks
- decode: configuration of the decoder, where each entry corresponds to a configurable ResNet block with upsampling; a bottleneck block is required
    - in_channels: number of input channels
    - expansion: channel expansion factor used within the residual blocks
    - stride: convolution stride, where the stride factor controls the upsampling operation
    - intermediate_channels: number of intermediate feature channels
    - num_residual_blocks: number of residual blocks
- output: configuration of the output layer
    - in_channels: number of input channels to the output layer
    - out_channels: number of output channels

PS: Decoder subblocks are required to mirror the encoder subblocks in terms of block count, number of residual blocks and spatial dimensions, with an additional bottleneck subblock matching the spatial dimension of the encoder’s final subblock.

For more details see: deep_learning/models/unsupervised/unet_resnet.py; 

```python
unet_conf = dict(
    input=dict(
        img_shape=(3, 32, 32), 
        out_channels=64,

                     expansion=4,
```

## Developed a custom training class that encapsulates the training loop, optimization, and evaluation

Unde:

- model - model to train, validate and evaluate
- optimizers - optimizers that trains the parameters of the model, 
- criterion  - function that quantifies the error between the model output and the ground-truth labels and provides the signal used for optimization
- device     - hardware on which tensors and computations are executed
- callbacks  - list of *callbacks* to customize the training loop
- metrics    - a dictionary string to metric values that returns evaluation output (always contains labels), to be used to compute metrics
- model_type -  "raw"      - do nothing
                "scripted" - turns PyTorch models and functions into TorchScript
                "compiled" - accelerates PyTorch models by dynamically compiling
- inputs_transforms - a function that applies predefined transformations to the input image data
- target_transforms - function that applies transformations to the input image to produce the output image; any spatial modifications must be applied consistently by the model
- lr_schedulers - learning-rate scheduling strategies that adjust the optimizer’s learning rate during training


## Developed modular metrics module to implement for automated evaluation of the model;
Implemented two metrics to evaluate the model’s performance: `MAEMetrics` and `MSEMetrics`.
- `MAEMetrics` computes the mean absolute error, which show linear errors.
- `MSEMetrics` computes the mean squared error, which show large errors more heavily. 



## Developed custom loss function to optimize the generation of images;
Cel mai raspandite functii de cost pentru a genera imagi sunt valoarea media absoluta `MAE` si valoarea medie patrata `MSE`.
- `MAE` which penalizes errors linearly. This results in slower convergence of large errors, produces clearer outputs, and is less sensitive to outliers.
- `MSE` which penalizes large errors more heavily. It is sensitive to outliers, since a single extreme pixel can contribute significantly to the loss. In generative tasks, it often produces blurrier images because it minimizes the squared difference across the entire image, effectively averaging uncertain regions.

Chose these two losses because they complement each other: `MAE` provides robustness to outliers and preserves clarity, while `MSE` emphasizes large errors, highlighting areas where predictions deviate strongly from the ground truth. 

```python
class MAEMSELoss(nn.Module):
   def __init__(self, alpha=0.5):
      super().__init__()
      self.alpha = nn.Parameter(torch.tensor(alpha))

   def forward(self, pred, target):
      l1 = torch.mean(torch.abs(pred - target))
      l2 = torch.mean((pred - target) ** 2)
      return self.alpha * l1 + (1 - self.alpha) * l2
```
